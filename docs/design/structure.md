# structure.md — superseded 2026-08-06

This file held the layout **rules** and this project's **instance** of them in one document. It has
been split, because that mixture had a cost worth recording.

| What you want | Where it is now |
|---|---|
| the rules — layers, slices, segments, dependency direction | [`laws/_StructureLaw.md`](../../laws/_StructureLaw.md) |
| our layers, our nine domains, our exceptions | [`documentation/_StructureDocumentation.md`](../../documentation/_StructureDocumentation.md) |

**Why it mattered.** While the rules and the description lived together, there was no way to tell
whether a sentence was binding or merely observing. When `domains/operator` was questioned three times
for holding both authentication and the people who do the work, the answer each time was drawn from
this file — and nobody could tell whether "it holds two things" was a rule violation or a description
of the tree. It was neither: it was a **missing** rule, now
[`_StructureLaw §5b`](../../laws/_StructureLaw.md).

A law is copied verbatim between projects; a Documentation is written fresh. A file that is half each
is portable to nowhere and authoritative about nothing.
